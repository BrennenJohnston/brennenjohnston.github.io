A teacher at a state services-for-the-blind agency needed a reliable tool to help people who had recently lost their vision, and didn't know braille yet, learn to identify elevator buttons through touch.

Using ADA (Americans with Disabilities Act) specifications for elevator signage, I designed a flashcard-style learning tool: a set of printed tiles, each carrying one raised elevator button number or symbol at accurate size and depth. Practicing with the tiles builds the tactile recognition needed to use real elevator panels confidently.

The two published files are used together: print the button numbers and symbols tiles and the matching tray, which holds and organizes the tiles for practice. Both are linked above, so anyone can print a complete set.
