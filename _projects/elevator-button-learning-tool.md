A teacher at a state services-for-the-blind agency needed a reliable tool to help people who had recently lost their vision — and didn't know braille yet — learn to identify elevator buttons through touch.

Using ADA specifications for elevator signage, I designed a flashcard-style learning tool: a set of printed tiles, each carrying one raised elevator button number or symbol at accurate size and depth. Practicing with the tiles builds the tactile recognition needed to use real elevator panels confidently.

Although this was a custom build for one instructor, the files are published, so anyone can print a set.
