I'm experimenting with [BumpMesh](https://bumpmesh.com/), a tool that applies tactile, fidget-friendly textures to 3D-printable models. The photo above shows several test prints, each carrying a different texture, from a fine pebbled grain to large rocky bumps and a ridged band.

The goal is to build up a working understanding of which textures print cleanly on an FDM printer and read well by touch. That knowledge is meant to feed into [tactile map making]({{ '/projects/tactile-maps/' | relative_url }}), where distinct, reliably printable surface textures can help distinguish map features by feel.
